# 화면 문구 원칙

정치·사회 뉴스를 다루는 서비스라 "서비스 자체가 한쪽 편을 든다"는 오해를 받지 않도록 표현을 통일합니다. (11/3 남지원 결정)

## 1. 말투: 합니다체

- O "야당 인용 비중이 같은 이슈의 다른 기사보다 높습니다"
- X "야당 인용 비중이 높아요"
- 버튼·배지·그래프 이름처럼 짧은 이름표는 명사형으로 씁니다 (예: "야당 인용 없음", "예시 기록 불러오기").

## 2. '편향'이라는 단어는 두 곳에만

- 서비스 이름 "뉴스 편향도 분석", 사용자 화면 "내 읽기 편향"에만 씁니다.
- 기사에는 '편향'을 붙이지 않습니다. 기사는 **판정하지 않고 비교**합니다.
  - O "같은 이슈를 다룬 다른 기사와 비교하면", "인용 비중", "인용 없음"
  - X "편향된 기사", "이 기사의 편향도 70%"

## 3. 빠진 출처는 사실만: "○○ 인용 없음"

- O "야당 인용 없음 (같은 이슈의 다른 기사에는 있습니다)"
- X "야당 관점 없음", "야당 입장을 무시함"

## 4. 프레이밍 어휘 = 화면에서는 "평가가 담긴 표현"

- 화면: "평가가 담긴 표현" (예: 돌려막기, 생색내기, 실질적인 도움)
- 시연·보고서·기술 설명: "프레이밍 어휘"라고 설명합니다.
  - 설명 예: "같은 사실을 전하면서도 바라보는 시선이 묻어나는 단어를 프레이밍 어휘라고 하고, 화면에서는 일반 사용자가 이해하기 쉽게 '평가가 담긴 표현'으로 보여 줍니다."

## 5. 색은 중립적으로

- 출처 유형 색에 빨강·파랑(정당 연상 색)을 쓰지 않습니다. 지금은 청록·주황·보라·회색.

## 6. 근거를 늘 함께

- 숫자·비교 문구에는 근거 문장(문장별로 보기)이나 해당 기사 링크를 함께 보여 줍니다.
